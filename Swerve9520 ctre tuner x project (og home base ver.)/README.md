# FRC Team 9520 — 2025-26 Robot Code

Robot code for FRC Team 9520, built on WPILib 2026 with a CTRE Phoenix 6 swerve drivetrain generated by Tuner X. This project is the "OG home base" version used for development.

## Hardware Overview

| Mechanism      | Motor(s)              | CAN ID(s) |
|----------------|-----------------------|-----------|
| Swerve drive   | TalonFX (via Tuner X) | see [TunerConstants.java](src/main/java/frc/robot/generated/TunerConstants.java) |
| Shooter        | TalonFX               | 13 |
| Shooter feed   | TalonFX               | 14 |
| Intake         | TalonFX               | 15 |
| Intake arm     | TalonFX               | 19 |
| Climber left   | TalonFX               | 16 |
| Climber right  | TalonFX               | 17 |

Vision: Limelight 4 (managed by [VisionSubsystem.java](src/main/java/frc/robot/subsystems/VisionSubsystem.java)) plus an optional Jetson coprocessor pipeline ([JetsonVision.java](src/main/java/frc/robot/subsystems/JetsonVision.java)).

## Software Stack

- **WPILib** 2026 (GradleRIO 2026.2.1, Java 17)
- **CTRE Phoenix 6** 26.1.3 — swerve drivetrain, TalonFX control
- **PathPlanner** 2026.1.2 — autonomous path following
- **PhotonLib** + Limelight — AprilTag / target tracking
- **Grapple FRC** 2026, **Playing With Fusion** 2026 — vendor sensors

Vendor dep manifests live in [vendordeps/](vendordeps/).

## Controls (Xbox controller, port 0)

| Input             | Action |
|-------------------|--------|
| Left stick        | Field-centric translation (forward / strafe) |
| Right stick X     | Rotation |
| **A** (hold)      | Brake (X-lock wheels) |
| **B** (hold)      | Auto-aim to current target |
| **Y** (hold)      | Spin up shooter; feeder starts automatically once at speed |
| **X**             | Toggle intake on/off |
| **LB**            | Reset field-centric heading |
| **RB**            | Toggle hub ↔ trench targeting |
| **LT** (hold)     | Intake arm down |
| **RT** (hold)     | Intake arm up |
| **D-pad ↑ / ↓**   | Both climbers up / down |
| **D-pad ← / →**   | Left / right climber individually |
| **Right stick click** | Toggle individual climber direction (UP/DOWN) |
| **Back + Y/X**    | SysId dynamic forward / reverse |
| **Start + Y/X**   | SysId quasistatic forward / reverse |

Stick mapping (default drive and auto-aim): **−LeftY = forward, −LeftX = left, −RightX = counter-clockwise** — see `driverVelocityX/Y` in RobotContainer.

Max speed is currently scaled to **0.75×** for practice — see `MaxSpeed` in [RobotContainer.java:33](src/main/java/frc/robot/RobotContainer.java#L33). Bump back to `1.0` for competition.

## Dashboard (Elastic / SmartDashboard)

- **Auto Chooser** — picks the auto routine (default: *Shoot All (Stationary)*).
- **Target Mode** — switches the Limelight 4 pipeline between Hub Blue / Hub Red / Trench Blue / Trench Red. Defaults to the alliance-correct hub on disable.
- **Shooter/ShooterRPS**, **Shooter/FeedRPS** — live-tunable shooter velocity setpoints.
- **Intake/Running**, **Climber/Dir** — status indicators.

## Building & Deploying

This is a standard GradleRIO project. From the project directory:

```bash
./gradlew build         # compile + run tests
./gradlew simulateJava  # run in simulation with sim GUI
./gradlew deploy        # deploy to the connected roboRIO
```

The team number is read from `.wpilib/wpilib_preferences.json` (or pass `-PteamNumber=9520`).

### Prerequisites
- WPILib 2026 VS Code install (provides the Java 17 toolchain WPILib expects)
- CTRE Phoenix 6 tools (Tuner X) for swerve calibration and regenerating [TunerConstants.java](src/main/java/frc/robot/generated/TunerConstants.java)

## Regenerating Swerve Constants

The swerve module offsets, gear ratios, CAN IDs, and gains in [generated/TunerConstants.java](src/main/java/frc/robot/generated/TunerConstants.java) come from CTRE Tuner X. After re-running the swerve project generator in Tuner X (`tuner-project.json`), export and overwrite that file — do not hand-edit it.

## Simulator

This project runs in the Team 9520 autonomy simulator (truth vs estimate, drift,
web UI). From the repository root run `./sim.sh` and open http://localhost:5173.
See [docs/simulator.md](../docs/simulator.md). Simulator code lives in
`src/main/java/frc/robot/sim/` and only runs in simulation.
